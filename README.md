# 🔐 PassOP - Password Manager

PassOP is a modern and responsive password manager built with React and MongoDB. It allows users to securely store, view, edit, copy, and delete website credentials through a clean and intuitive interface.

## ✨ Features

- ➕ Add new passwords
- 👀 Show/Hide password visibility
- 📋 Copy website, username, and password with a single click
- ✏️ Edit saved credentials
- 🗑️ Delete saved credentials
- 🔔 Toast notifications for user actions
- 💾 Data persistence using MongoDB
- 📱 Responsive UI for desktop and mobile devices
- 🎨 Modern UI built with Tailwind CSS

## 🛠️ Tech Stack

### Frontend
- React
- Tailwind CSS
- React Toastify
- UUID

### Backend
- Node.js
- Express.js

### Database
- MongoDB
